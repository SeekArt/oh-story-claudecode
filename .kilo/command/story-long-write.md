长篇网络小说写作辅助。从大纲到正文，辅助长篇网络小说的创作。

触发方式：/story-long-write、「开书」「写大纲」「长篇写作」

工作流程：
1. 题材定位与核心梗设计
2. 世界观构建
3. 大纲排布（卷纲 + 细纲）
4. 角色设定
5. 正文写作（日更/批量续写）
6. 一致性检查

输出文件结构：
- {书名}/设定/世界观/
- {书名}/设定/角色/

- {书名}/正文/
