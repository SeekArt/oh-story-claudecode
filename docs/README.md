## 快速链接

### 新用户

1. 阅读 [README.md](../README.md) 了解项目概览
2. 根据你的工具选择安装方式：
   - Claude Code / OpenClaw：使用 npx skills add
   - Kilo：克隆项目或复制配置
   - 其他工具：参考迁移指南
3. 运行 `/story-setup` 部署环境
4. 开始使用 `/story` 或具体 skill

### 迁移用户

如果你从其他工具迁移到本项目：
1. 阅读 [migration-guide.md](migration-guide.md)
2. 检查配置差异对比
3. 按步骤迁移

### Agent 使用

了解 Agent 调用方式：
1. 阅读 [agent-compatibility.md](agent-compatibility.md)
2. 根据你的工具选择调用方式
3. 参考 Agent 清单选择合适的 Agent
