# 文风提取输出模板

> **何时加载**：story-style-extract Step 6 填写输出时。
>
> **模板依据**：基于 `story-long-analyze/references/style-profile-protocol.md` 简化为独立版本。
> 与完整版的差异：去除了依赖拆文库的「可借鉴技巧」「情绪交替统计」「拆文报告引用」段。

## 模板

```markdown
# {书名/来源名} 文风

## 生成记录
- 源文件/目录：{原始输入路径}
- 抽样章节：第 {K1}/{K2}/{K3} 章（或起始/中段/结尾段落）
- 生成时间：{date}
- 总字数：{N} 字
- 文风可用：是  # 若样本不足或测量失败，写“否：原因”

## 整体语感
- 句长分布：{短句(<15字) X%、中句(15-30)Y%、长句(>30)Z%、平均句长 N 字、标点密度 M%。一句概括语感。}
  - confidence: high（确定性测量）
- 标点习惯：{破折号/省略号/句号/感叹号/分号的高频用法。附 2-3 个原文短片段示例。}
  - confidence: high | med | low
- 段落节奏：{平均段长、单段单动作 vs 多动作堆叠、断行习惯。}
  - confidence: high | med | low

## 对话技法
- 潜台词模式：{2-3 种典型潜台词手法（问非所答 / 语气反差 / 信息隐瞒等），每种附 1 段原文示例。}
  - confidence: high | med | low
- 对话标签习惯：{说话动词多样性、动作替代说话标签的频率、对话与动作的穿插比例。}
- 角色语气区分：{角色间的语言差异或统一度描述，引用原文样本句。}

## 情绪基调
- 整体倾向：{文本主要基调（紧张/轻松/悲伤/热血等）}
- 章内基调切换：{段落间是否频繁切换基调，切换频率如何}
- 典型节奏：{是否有固定的节奏模式，如「紧张→放松→紧张」或「铺垫→爆发→收束」}

## 句式特征
- {典型句式偏好的简要描述，如「多用短句堆叠」「偏好长句铺陈」「排比句频繁出现」等}

## 原文锚点片段

> 每片段 300-500 字，**用于写作时 few-shot**。模仿手法、不抄字句。

### 片段 A — 基调：{基调名}
**出处**：{来源标识}
**示范点**：{短句堆叠节奏 / 标点位置 / 对话潜台词手法 等}

```
{300-500 字原文，逐字连续切片，禁止改写}
```

### 片段 B — 基调：{基调名}
**出处**：{来源标识}
**示范点**：{示范点}

```
{300-500 字原文}
```

### 片段 C — 基调：{基调名}
**出处**：{来源标识}
**示范点**：{示范点}

```
{300-500 字原文}
```

### 片段 D — 基调：{基调名}
**出处**：{来源标识}
**示范点**：{示范点}

```
{300-500 字原文}
```

> 优先覆盖文本中实际存在且样本充足的基调。缺哪个基调就写「该基调样本不足，跳过」。

## 写作约束建议
- {基于提取结果的写作建议，如「叙述用短句快速推进」「对话大量使用动作穿插」「避免长段独白」等。可选，可空。}
```

## 字数预算

- 硬上限 ~3000 字（因为不包含对标书的 可借鉴技巧 段）
- 描述部分 ≤ 1500 字
- 原文锚点 4 段 × 300-500 字 ≈ 1200-2000 字

## 与文风优先级决议表的兼容

本模板输出直接兼容 narrative-writer 的「文风优先级决议表」。写作端读取时的规则：

| 约束维度 | 类型 | 与本输出冲突时 |
|---------|------|--------------|
| Gate A 禁用词 / banned-words.md | 硬 | 禁令优先 |
| Gate F 章末禁升华 / 禁感叹收尾 | 硬 | Gate F 优先 |
| 禁止万能比喻 | 硬 | 禁令优先 |
| 字数下限 | 硬 | 字数下限优先 |
| 三维度织入 | 默认软 | 文风可调密度，不取消织入 |
| Gate D 句长拆短 | 默认软 | **文风优先**（在文风句长带内） |
| Gate B 句式去套路 | 默认软 | **文风优先** |
| 标点习惯 | 默认软 | **文风优先** |
| 对话潜台词模式 | 默认软 | **文风优先** |
