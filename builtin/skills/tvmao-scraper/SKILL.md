# TVMao 剧情抓取技能

从电视猫（tvmao.com）抓取电视剧/电影的分集剧情。

## 功能特性

- 支持按剧名搜索获取剧集ID
- 支持直接使用剧集ID抓取
- 自动识别分集列表和剧情正文
- 按剧名目录与集数保存到本地
- 支持单集或全剧抓取

## 使用方式

### 技能触发

用户请求示例：
- "从电视猫抓取神盾局特工的分集剧情"
- "抓取 https://www.tvmao.com/drama/ai4vJS8=/episode 的剧情"
- "抓取剧集ID ai4vJS8= 的所有分集"
- "/tvmao-scrape 神盾局特工"
- "/tvmao-scrape --id ai4vJS8="

### 脚本位置

```
scripts/tvmao_scraper.py
```

### 基本用法

```bash
# 搜索剧名并抓取全部
python scripts/tvmao_scraper.py --search "神盾局特工"

# 使用剧集ID抓取全部
python scripts/tvmao_scraper.py --id ai4vJS8=

# 抓取单集
python scripts/tvmao_scraper.py --id ai4vJS8= --episode 1

# 指定输出目录
python scripts/tvmao_scraper.py --id ai4vJS8= --output ./剧情

# 抓取指定范围
python scripts/tvmao_scraper.py --id ai4vJS8= --start 1 --end 10
```

### 参数说明

| 参数 | 说明 |
|------|------|
| `--search` | 按剧名搜索并抓取 |
| `--id` | 指定剧集ID（URL中的加密ID） |
| `--episode` | 抓取指定集数 |
| `--start` | 起始集数 |
| `--end` | 结束集数 |
| `--output` | 输出目录（默认：./episodes） |
| `--format` | 输出格式：txt/markdown（默认：txt） |

## 工作流程

1. **搜索或访问**：根据剧名搜索或直接访问剧集页面
2. **解析分集列表**：提取所有分集的URL和集数
3. **抓取每集剧情**：
   - 提取剧集标题
   - 提取剧情正文（去除广告和无关内容）
   - 保存为文本文件
4. **组织目录结构**：
   ```
   输出目录/
   └── 剧名/
       ├── 第01集.txt
       ├── 第02集.txt
       └── ...
   ```

## 页面结构规则

### 分集列表页面

URL格式：`https://www.tvmao.com/drama/{剧集ID}/episode`

关键元素：
- 剧名：`<strong class="font24">{剧名}</strong>`
- 分集链接：`.epipage li a` 包含分集URL
- 总集数：`共{数字}集`

### 单集剧情页面

URL格式：`https://www.tvmao.com/drama/{剧集ID}/episode` 或 `/episode/{集数路径}`

关键元素：
- 集数标题：`<p class="epi_t">{标题}</p>`
- 剧情正文：`<article class="clear epi_c">` 内的 `<p>` 标签

## 依赖

- Python 3.7+
- requests
- beautifulsoup4

安装依赖：
```bash
pip install requests beautifulsoup4
```

## 注意事项

1. 请遵守网站robots.txt和使用条款
2. 建议添加请求延迟避免频繁访问
3. 剧情内容版权归电视猫所有，仅供个人学习使用
4. 如遇反爬限制，可能需要添加Cookie或使用代理
